# 截图放置说明

建议将项目展示截图统一放在本目录下，并按如下命名：

- `home.png`：首页总览
- `checkin-modal.png`：打卡弹窗
- `water-reminder.png`：喝水提醒弹窗
- `water-page.png`：喝水页设置与记录
- `mood-page.png`：心情树洞页
- `stats.png`：学习统计或项目累计统计

截图建议使用清晰的 PNG 文件，避免模糊缩放图。
